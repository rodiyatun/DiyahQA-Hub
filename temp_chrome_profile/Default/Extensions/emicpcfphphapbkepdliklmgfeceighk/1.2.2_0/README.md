# Focus: The Elements - DOM Inspector & Editor
### DOM Manipulation Tool

A lightweight Chrome Extension that allows you to **inspect, edit, and customize any webpage in real-time**.

## ✨ Features
- Inspect element styles (size, font, colors, margins, paddings)
- Edit properties in real-time (width, height, font, colors, etc.)
- Reset changes to original state
- Copy generated CSS with a single click
- Draggable popup for flexibility
- Auto positioning to avoid cutting off

## 🚀 Installation
1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer Mode** (toggle in the top right).
4. Click **Load unpacked** and select this folder.
5. The extension icon will appear in the toolbar.

## 🛠 Usage
- Hover over elements → See style properties in popup.
- Double-click element → Open **Edit Popup**.
- Edit properties → See **real-time changes**.
- Copy → Copy CSS rule for the element.
- Reset → Restore original styles.
