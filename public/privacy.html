Kebijakan Privasi

Privacy Policy • Berlaku sejak: 15 Agustus 2026

Kami berkomitmen untuk melindungi privasi Anda. Dokumen ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi Anda.

1. Informasi yang Kami Kumpulkan

Kami mengumpulkan informasi berikut saat Anda menggunakan DiyahQA Hub:

  • Data Akun: Alamat email, nama, dan role pengguna yang Anda daftarkan.
  • Data Kerja: Project, test case, bug report, dan semua konten yang Anda buat di dalam aplikasi.
  • Data Preferensi: Pengaturan workspace, bahasa, dan konfigurasi integrasi.
  • Data Teknis: Log error anonim yang digunakan untuk debugging dan peningkatan kualitas.

2. Cara Kami Menggunakan Data

Data yang kami kumpulkan digunakan untuk:

  • Menyediakan, mengelola, dan meningkatkan layanan aplikasi kepada Anda.
  • Menyinkronkan data Anda secara aman antar perangkat via Supabase Cloud.
  • Mengidentifikasi dan memperbaiki bug serta masalah teknis.
  • Mengirimkan notifikasi penting terkait layanan (bukan marketing).

3. Berbagi Data dengan Pihak Ketiga

✅ Kami TIDAK menjual, menyewakan, atau menukar data pribadi Anda kepada pihak ketiga mana pun untuk tujuan pemasaran.

Data dapat dibagikan hanya dalam situasi berikut:

  • Penyedia Infrastruktur: Supabase (penyimpanan database cloud) — data dienkripsi at-rest dan in-transit.
  • Kewajiban Hukum: Jika diwajibkan oleh hukum atau perintah pengadilan yang berlaku.

4. Keamanan Data

Kami menerapkan langkah-langkah keamanan berikut untuk melindungi data Anda:

  • Enkripsi TLS/SSL untuk semua transmisi data.
  • Row Level Security (RLS) di Supabase untuk isolasi data antar pengguna/workspace.
  • Password di-hash menggunakan bcrypt (tidak pernah disimpan dalam plaintext).
  • Akses database dibatasi hanya untuk staf yang berwenang.

5. Hak-Hak Anda

Anda memiliki hak-hak berikut terkait data pribadi Anda:

  • Akses: Meminta salinan data pribadi yang kami simpan tentang Anda.
  • Koreksi: Memperbarui atau memperbaiki data yang tidak akurat.
  • Penghapusan: Meminta penghapusan akun dan semua data Anda.
  • Portabilitas: Mengunduh data Anda dalam format yang dapat dibaca mesin.
  • Keberatan: Menolak pemrosesan data tertentu.

6. Retensi Data

Data Anda disimpan selama akun Anda aktif. Jika Anda menghapus akun:

  • Semua data personal akan dihapus dalam 30 hari.
  • Backup otomatis dihapus dalam 90 hari.
  • Log anonim yang tidak dapat diidentifikasi dapat disimpan lebih lama untuk analisis.

7. Cookie dan Penyimpanan Lokal

Aplikasi menggunakan localStorage browser untuk menyimpan preferensi pengguna (misalnya workspace aktif, pengaturan bahasa). Data ini tidak dikirim ke server kami.

8. Anak di Bawah Umur

DiyahQA Hub tidak ditujukan untuk pengguna di bawah 17 tahun. Kami tidak secara sengaja mengumpulkan data dari anak di bawah umur.

9. Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan material akan diberitahukan melalui notifikasi dalam aplikasi setidaknya 14 hari sebelumnya.

10. Hubungi Kami

Jika Anda memiliki pertanyaan, kekhawatiran, atau ingin menggunakan hak-hak Anda, hubungi kami di:

  • Email: privacy@diyahqa.com
  • Support: support@diyahqa.com
