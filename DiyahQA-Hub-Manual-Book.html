BAB 1Pendahuluan

1.1 Pengenalan DiyahQA Hub

DiyahQA Hub adalah aplikasi desktop berbasis Electron + React yang dirancang khusus untuk tim Quality Assurance (QA). Aplikasi ini menyediakan satu platform terpadu untuk mengelola seluruh aktivitas QA mulai dari penulisan test case, pelaporan bug, perencanaan pengujian, hingga pembelajaran QA melalui berbagai modul lab interaktif.

Semua data tersimpan secara lokal di database SQLite yang terenkripsi pada perangkat pengguna, sehingga data tidak dikirim ke server eksternal kecuali saat menggunakan fitur integrasi Plane.so atau notifikasi Google Chat.

ℹ️ Informasi Platform
Aplikasi ini tersedia untuk macOS (Apple Silicon / arm64). Data tersimpan lokal di: ~/Library/Application Support/DiyahQA Hub/

1.2 Fitur Utama

🐛

Bug Report Management

Catat, kelola, dan transfer bug report ke Plane.so dengan satu klik. Lengkap dengan tracking status real-time.

✅

Test Case Management

Buat dan kelola test case dengan field lengkap. Import dari CSV atau Allure JSON.

📋

Test Plans & Runs

Buat test plan, assign test cases, dan track hasil eksekusi per environment.

📝

Requirements Traceability

Kelola requirements dan hubungkan ke test cases untuk traceability matrix.

✈️

Integrasi Plane.so

Transfer bug report langsung ke workspace Plane dengan mapping field otomatis.

💬

Google Chat Notification

Broadcast otomatis ke Google Chat saat bug ditransfer ke Plane.

🔬

SQL Lab

Latihan SQL dengan HR Schema dan challenges interaktif langsung di browser.

🎭

Automation Lab

Playwright Academy dengan tutorial interaktif dan contoh kode otomasi.

🔒

Security Lab

Simulasi OWASP Top 10 dan konsep security testing.

⚡

Performance Lab

Panduan k6 dan Gatling untuk performance testing.

1.3 Instalasi Aplikasi

  1. Download file DiyahQA Hub-1.0.0-arm64.dmg dari distribusi resmi
  2. Double-click file DMG untuk membuka installer
  3. Drag ikon DiyahQA Hub ke folder Applications
  4. Klik kanan pada aplikasi di folder Applications → pilih Open (karena aplikasi belum memiliki code signing resmi)
  5. Pada dialog keamanan macOS, klik Open untuk mengkonfirmasi
  6. Aplikasi akan membuka dan membuat database lokal secara otomatis
⚠️ Perhatian Keamanan macOS
Jika muncul pesan "aplikasi tidak dapat dibuka karena developer tidak teridentifikasi", buka System Settings → Privacy & Security dan klik "Open Anyway" di bagian bawah halaman.
